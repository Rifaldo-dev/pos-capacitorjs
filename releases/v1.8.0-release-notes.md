# POS UMKM Rifaldo v1.8.0 — Product Action Three-Dot Menu

Rilis **v1.8.0** menyempurnakan tampilan daftar produk dengan merapikan tombol aksi pada tabel katalog menjadi menu **tiga titik (ellipsis `⋮`)**.

## Fitur Utama v1.8.0

1. **Menu Aksi Tiga Titik (`⋮`) pada Produk**:
   - Kolom aksi pada tabel daftar produk kini menggunakan tombol ikon tiga titik yang bersih dan profesional.
   - Saat ditekan, muncul menu pop-up berisi pilihan: **Edit produk**, **Atur stok**, **Aktifkan/Nonaktifkan**, dan **Hapus produk**.
   - Desain ini menghemat ruang secara signifikan, terutama pada perangkat seluler dengan layar sempit, menjaga konsistensi antarmuka dengan menu Pengaturan.

2. **Performa & Stabilitas 100% Offline**:
   - Tetap mempertahankan seluruh fitur unggulan v1.7.0 (senter native, multi-scan kasir, barcode-first, dan database SQLite lokal).
   - Seluruh perubahan diverifikasi dengan lint, unit test, dan web build tanpa error.
