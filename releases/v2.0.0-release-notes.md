# POS UMKM Rifaldo v2.0.0

Major visual polish release featuring modern, professional SVG navigation icons and complete offline stability.

## What's New
- **Refined Navigation Icons**: Replaced basic symbol icons with custom, clean vector SVG icons for Beranda, Kasir, Produk, Stok, Transaksi, and Pengaturan.
- **Active State Glow & Contrast**: Enhanced bottom navigation active state with pill styling and touch feedback.
- **Full Offline Native POS**: Retains all features including native CameraX multi-scan, flashlight toggle, barcode-first product creation, and SQLite offline storage.

## Installation
Download `pos-rifaldo-nav-icons-debug.apk` and install it on your Android device. Package ID: `pos.rifaldo`.
