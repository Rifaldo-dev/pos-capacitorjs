# Rilis APK Ini POS

Direktori ini berisi kumpulan file APK (Android Package) untuk aplikasi **Ini POS** yang siap diinstal pada perangkat Android.

## Cara Instalasi
1. Unduh file `.apk` terbaru (misal: `pos-inipos-debug.apk`).
2. Jika diminta, izinkan instalasi dari "Sumber tidak dikenal" pada pengaturan Android Anda.
3. Buka file APK untuk memulai proses instalasi.

## Daftar Rilis
*   **v2.5.0**: Tracking visual barcode real-time pada kamera native, menampilkan kotak deteksi dan label format/kode, serta peningkatan pengalaman multi-scan.
*   **v2.4.0**: Rebranding resmi menjadi **Ini POS**, backup mandiri melalui Android Share Sheet, ekspor laporan Excel/PDF, dan peningkatan stabilitas scanner native.
*   **v2.3.0**: Penambahan fitur laporan penjualan dan filter tanggal.
*   **v2.2.0**: Redesain dashboard dan dukungan foto produk.
