## POS UMKM Rifaldo v1.5.0

This release replaces the WebView/JavaScript scanner with a fully native Android scanner exposed through a local Capacitor Plugin/Bridge.

### Native offline scanner

- Camera preview and frame analysis are handled natively with CameraX.
- Barcode and QR detection use the bundled Google ML Kit barcode model.
- No HTML scanner, WebView decoder, CDN, server, API, or runtime model download is used.
- Camera permission is declared in Android and requested at runtime by the plugin.
- Supported formats: EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, ITF, and QR Code.
- Scan results return through the Capacitor bridge to React.
- Existing local database behavior is preserved: found products are added to the cart; unknown barcodes open the Add Product form with the barcode prefilled.
